大会ナンバー受付 Web/PWA v1

■目的
Android/iPhone/PCのブラウザで共通利用する大会受付システムの試作品。
音声認識だけに依存せず、直接番号入力と「ムリ」ボタンを必ず用意する。

■対応
マラソン：1～99999
駅伝：1～9999 × 1～25区
駅伝の音声例：125-3 / 125の3 / 125の3区
「ムリ」：番号不明として1人加算
氏名：扱わない
属性：任意（v1ではまだ属性マスタなし）
大会名・開催日・地点・担当者・TOP予想：任意設定
Google Apps Script URL：任意

■公開方法
HTTPSで公開してください。GitHub Pages / Firebase Hosting / Cloudflare Pages等で運用可能です。
PWAのインストール可否はブラウザによって異なりますが、通常のURLとしても利用できます。

■重要
Web Speech APIの音声認識はブラウザ依存です。そのため、iPhoneを含む全端末で「音声が必ず動く」とは設計しません。
音声が利用できない場合は直接入力へ切り替えられる構造です。
